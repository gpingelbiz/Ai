# Ai

Greg Pingel's self-hosted AI tooling.

- [`opus-dropbox/`](opus-dropbox/): a client kit. Unedited videos dropped in the client's Dropbox go to their Opus Clip account, and the finished clips and captions come back into another Dropbox folder by themselves. It runs on the client's Mac and has no dependencies.
- [`reel-editor/`](reel-editor/): raw talking-head video → finished reel. Whisper transcript, silence and bad-take cuts, Pingel Brand captions, hook title, magic zooms, HyperFrames render, ElevenLabs SFX and voiceover. See its README for setup on the Mac Mini.
